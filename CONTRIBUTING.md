# contributing to cvssn.github.io

if you're reading this, you are probably interested in contributing to this project, which i'm very thankful for.

this document serves as a guide to help you make contributions that we can merge into the website codebase.

## translations

thank you for showing interest in making that idea more accessible around the world, i really appreciate it! here are some guidelines for how the translation should look:

- website's writing style is informal. please do not use formal language, unless there is no other way to express the same idea of the original text in your language.
- all website text is written in lowercase. this is a stylistic choice, please do not capitalize translated sentences.
- **please don't translate anything into languages which you are not experienced in.** we can use google translate ourselves, but we would prefer the project to be translated by humans, not computers.
